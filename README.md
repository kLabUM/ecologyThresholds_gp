# ecologyThresholds_gp: the reach-velocity method

This branch holds one thing: `reach_velocity/`, a self-contained, reproducible analysis that turns one survey campaign, one stage sensor and one ADCP into a season-long velocity record for a river reach, with uncertainty, and an ecological number learned from nest sites. It is the basis of the paper in preparation.

Start with `reach_velocity/README.md`. To rerun everything (about five minutes), see `reach_velocity/RERUN.md`. A coding agent working here should read `reach_velocity/CLAUDE.md` first.

The original notebooks and their outputs stay on `main`; nothing here depends on them.
